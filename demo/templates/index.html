📊 모델 검증 근거 — 왜 미래 예측을 신뢰할 수 있는가?
TTM+GRU 모델이 2020~2024 실제 데이터에서 얼마나 잘 맞혔는지 검증한 결과입니다.
검증 구조: 2020~2023 학습 → 2024 완전 out-of-sample 블록 백테스트 (91블록 × 96h)
핵심 결론: 2024년 8,784시간 예측에서 TTM RMSE 111 MWh — 실측 대비 오차율 약 17%
미래 적용: TTM 96h 블록 연쇄 합성 이력 → 2025~2027 시나리오 (Hybrid roll 아님)

Prophet+GRU 대비 우리 방식의 장점
❌ Prophet + GRU
  • Prophet이 추세·계절성 수동 분해
  • GRU가 잔차를 별도 학습 → 2단계 오차 누적
  • 하이퍼파라미터 이중 튜닝 필요
  • 기온 등 외부 변수 파이프라인 별도 필요
✅ TTM (frozen) + GRU (우리)
  • TTM이 512h 패턴을 자동 임베딩
  • GRU는 지역 특화 head만 학습 → 단순
  • 기온 proxy(climatology)로 대체 가능
  • 96h one-shot 예측 → 오차 누적 없음
⚡ 실시간 예측 — 인풋
512h 컨텍스트 → frozen TTM 96h one-shot (4일 한 번에 예측)

※ 2025→2024 · 2026→2023 · 2027→2022 실측 매핑 (연도마다 다른 패턴). 명절은 설날 양력 차이 → 해당 소스 연도 설 기준 일수 오프셋.
