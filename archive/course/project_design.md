# 프로젝트 설계서
## 지역별·기온 변화에 따른 전력 소비 패턴 분석

> **청자 기준:** 에너지·정책에 관심 있는 일반 청중 / 학부 심사위원
> **핵심 원칙:** 어려운 모델 이야기보다 "왜, 무엇을, 어떻게 썼는가"가 먼저다.

---

## 1. 이 프로젝트를 한 문장으로

> **"지역마다 전력 쓰는 방식이 다른데, 지금 관리 방식은 다 똑같다. 데이터로 그 차이를 보여주고, AI로 예측까지 해봤다."**

청자가 기억해야 할 문장은 이것 하나다.

---

## 2. 문제 — 청자가 바로 공감할 수 있는 방식으로

### 현실 상황
```
서울 한여름 오후 3시           강원도 한겨울 새벽 3시
에어컨 풀가동                   전기장판·보일러 풀가동
전력 수요 폭증                  전력 수요 폭증

→ 두 상황이 완전히 다른데, 지금 예비 전력 관리는 같은 기준으로 운영
```

### 왜 문제인가
- 여름 서울에서 전력이 부족하면 → 강원도 예비 전력까지 끌어다 씀
- 겨울 부산이 한파일 때 → 서울 기준으로 예비력 설정하면 부산이 위험
- **지역별 특성을 모르면 예비력을 어디에 얼마나 쌓을지 알 수 없다**

### 이 프로젝트가 주는 답
1. 지역마다 전력 패턴이 얼마나 다른지 **데이터로 시각화**
2. 그 패턴을 **AI가 예측**할 수 있음을 실증
3. → **지역 맞춤 관리 정책 수립의 근거 제공**

---

## 3. 데이터 — 무엇을 어디서 가져왔나

### 사용한 데이터 (3가지)

```
① 전력 데이터
   출처: 한국전력거래소(KPX) 공공데이터포털
   내용: 서울·부산·대전·강원 시간별 전력거래량(MWh)
   기간: 2020–2024년 (5년, 시간별)
   크기: 약 175,000행

② 기온 데이터
   출처: Open-Meteo Archive API (KMA ASOS 동등 품질)
   내용: 각 지역 시간별 실제 기온(°C)
   기간: 2020–2024년

③ 서울 자치구 데이터
   출처: 서울시 에너지 사용량 통계
   내용: 25개 자치구 월별 에너지 사용량
   용도: 서울 내부 지역 차이 보조 분석
```

### 왜 이 데이터인가
- 전력(KPX) + 기온(기상) = "날씨가 전력에 미치는 영향" 분석의 최소 구성
- 4개 지역 = 도시형(서울·부산·대전) + 자연형(강원) 비교
- 5년치 = 계절별 패턴 반복 확인 가능한 충분한 데이터

### ⚠️ 핵심 주의: "전력 소비량"이 아닌 "전력 거래량"

KPX 데이터는 **도매 전력시장 거래량**이다. 도시가 실제로 쓴 소비량과 다르다.

**거래량이 많은 지역 = 발전소가 많은 지역**

| 지역 | 평균 거래량 (2023) | 이유 |
|------|-----------------|------|
| 충청남도 | 11,210 MWh | 태안·보령 석탄발전소 집중 |
| 경기도 | 9,779 MWh | 대규모 산업·복합발전 |
| **부산시** | **4,094 MWh** | **고리·신고리 원자력 인근** |
| 강원도 | 3,855 MWh | 동해·삼척 발전소 |
| **서울시** | **562 MWh** | **발전소 없음 — 소비 전용** |
| **대전시** | **27 MWh** | **발전소 거의 없음** |

> 서울 인구(970만) > 부산 인구(340만) 인데도 거래량은 부산이 7배 높은 이유가 여기 있다.

**이것이 H2 slope 결과(부산 −32 vs 서울 −0.04)를 설명한다**
- 부산: 발전·거래 기반 지역 → 기온·계절 변화가 발전 패턴과 거래 흐름 모두에 영향
- 서울: 소비 전용 지역 → 기온과 무관하게 외부에서 구매, 거래량 변동 작음

**발표 표현:**
- ❌ "서울시 전력 **소비량**"
- ✅ "서울시 권역 전력 **거래량**"

정책 활용은 여전히 유효하다. 거래량 예측 = 해당 권역 예비력·송전 배분의 직접 근거.

## 4. 가설 — 3가지 질문과 그 답

### 가설을 세운 이유
> "그냥 데이터 보지 말고, 먼저 답을 예측하고 → 데이터로 맞는지 확인한다."
> 이것이 분석의 신뢰성을 높이는 방법.

---

### 가설 1. "기온이 오를수록 전력도 오를까?"

**예상:** 기온과 전력은 단순 선형이 아닌 **U자 형태**일 것이다.
- 너무 추우면(겨울) → 난방으로 전력 증가
- 딱 좋으면(봄·가을) → 전력 최소
- 너무 더우면(여름) → 냉방으로 전력 증가

**결과:** ✅ 맞다

```
전력
(MWh)
 ^
 |  *           *
 | * *         * *
 |  * *       * *
 |    * * * * *
 +-----|----18°C-----|---> 기온
    (겨울)         (여름)

        U형 곡선 확인
```

**발견:** 냉방보다 난방 구간의 기울기가 더 가파르다.
→ 서울은 여름보다 겨울에 기온 변화에 더 민감하게 반응한다.

---

### 가설 2. "서울이 기온 변화에 가장 민감할까?"

**예상:** 인구·상업 집중 → 에어컨·히터 사용량 → 서울이 가장 민감할 것

**결과:** ❌ 예상과 반대 — 그래서 더 흥미롭다

```
기온 1°C 변화 시 전력 변화량:

부산   ████████████████████████████████  -32.4 MWh  ← 가장 민감
대전   █  -1.3 MWh
강원   █  +1.5 MWh  (반대 방향 — 기온↑ → 전력↑)
서울   |  -0.04 MWh  ← 거의 반응 없음
       └──────────────────────────────────────────▶
```

**해석:**
- 서울은 절대 전력량은 최대지만, **기온이 아닌 업무 활동에 더 좌우됨**
- 부산은 기후 의존도가 높은 도시 → 폭염·한파 때 집중 관리 필요
- **"지역마다 다르다"는 주장의 가장 강한 근거**

---

### 가설 3. "평일 낮에 전력이 몰릴까?"

**예상:** 평일 09–18시 = 업무·공장 가동 → 전력 집중

**결과:** ✅ 맞다

```
전력
(MWh)
620 |        ▲ 평일 피크 (16시, 611 MWh)
600 |     /──────────────────\
580 |   /                    \
560 | /   평일                 \
540 |─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ 주말 (완만, 510-540)
520 |
500 |
    0   6   9   12  16  18  24  (시간)
         [████ 09-18h 집중 구간 ████]
```

**실용적 의미:**
- **오후 2–6시 = 수요관리(DR) 프로그램 집중 적용 시간대**
- 이 시간대 전력 피크를 10% 줄이면 예비력 확보에 큰 효과

## 5. 모델 — AI를 왜 썼나 (간략)

### 왜 필요한가

```
분석만 있으면:   "부산이 기온에 민감하다" → 그래서?
예측까지 있으면: "내일 35°C 예보 → 전력 X MWh 증가 → 예비력 확보"
```

분석 → 예측 → 행동으로 연결되어야 정책이 된다.

### 무엇을 썼나

- **IBM Granite TTM-r2** (사전학습된 시계열 AI) + **GRU 헤드** (서울 특화 추가 학습)
- 원안 계획(Prophet + GRU)과 동일한 철학: "구조를 아는 백본 + 지역에 적응하는 헤드"
- 서울 예측 오차: ±15.8 MWh (실제 전력 506 MWh 대비 약 **3%**)

### 무엇을 보여주는가

- 서울로 학습한 모델을 부산·대전·강원에 적용 → 지역마다 정확도 차이 발생
- 결론: **"지역별로 별도 관리·모델이 필요하다"** 는 주장의 실증적 근거

## 6. 결론 — 청자가 가져가야 할 3가지

### ① 지역마다 다르다 (데이터로 증명)
부산은 기온 1°C에 32MWh 반응, 서울은 0.04MWh.
같은 기준으로 관리하면 안 된다.

### ② 시간대가 다르다 (패턴 확인)
평일 오후 2–6시가 핵심 수요 집중 구간.
이 시간대 관리만 잘해도 전력 안정성 크게 향상.

### ③ 예측이 가능하다 (AI로 실증)
TSFM 기반 모델로 4일 앞 전력 수요를 3% 오차로 예측.
지역별 모델 구축 → 지역 맞춤 예비력 배분 가능.

## 7. 정책 활용 — 실제로 어떻게 쓰는가

```
지금:   전국 동일 기준 → 예비력 일괄 확보
                                   ↓ 비효율
앞으로: 기온 예보 + 지역별 예측 모델
        → 부산 35°C 예보 → 부산 예비력 +X MWh 자동 확보
        → 서울 공휴일   → 업무 전력 감소 예측 → 예비력 일부 해제
        → 강원 겨울 한파 → 관광·주거 난방 수요 급증 대비
```

| 발견 | 정책 연결 |
|------|---------|
| 부산 기온 민감도 최고 | 기상 경보 시 부산 우선 대응 |
| 서울은 업무 활동이 핵심 | 공휴일·연휴 캘린더 기반 관리 |
| 평일 09–18h 집중 | 이 시간대 DR 프로그램 집중 운영 |
| 강원 양의 slope | 관광·난방 시즌 별도 관리 기준 |
| AI 예측 가능성 실증 | 지역별 예측 시스템 구축 로드맵 |
